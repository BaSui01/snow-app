# ADR：子代理工具失败恢复与诊断

- 日期：2026-10-24
- 状态：修复契约已确定；构建、静态检查和运行验收分别记录。
- 范围：普通读取错误被升级为子代理终态失败、子代理 IPC 多订阅、预览更新配置遗漏。

## 事实与边界

日志中的 os error 2 表示文件不存在，不表示文件为空。普通空文本读取已有正常空结果分支。冻结预览的子代理循环在工具 Promise 拒绝后无条件停止，而非进程崩溃。缺少具体运行标识时，不把 RUN_BUSY、更新失败和读取错误推定为同一事件。临时文件的生产者、清理时机尚未查明，不猜测性修改其他项目文件。

## 决策

1. 不改数据库、IPC 参数/返回类型、工具权限、跨会话隔离、更新源或 MCP 协议；不新增依赖。复用现有 writeLog 系统日志入口。
2. 对 filesystem-read 的已知读取/解码/空图片/参数错误保守分类为可恢复工具失败：保留 error 工具卡及原始错误结果，反馈给模型决定修正路径或改用其他已授权操作，不自动重复调用。只有确知为普通读取错误才恢复；未知错误仍停止。权限门禁、取消、运行所有权、状态转换与持久化故障不得按普通读取错误继续。
3. 连续三个含可恢复读取失败的工具轮次停止并记录恢复预算耗尽；无此错误的完整轮次重置计数。预算限制循环，不重试工具，不改变模型/网络已有重试机制。
4. 工具开始/完成用 DEBUG，恢复决定用 WARN，致命停止用 ERROR，运行启动/终态提交用 INFO。日志只含运行/会话/调用标识、工具名、固定原因码、恢复决定、计数、耗时、普通空文本结果标志；不含工具参数、路径、文件正文、提示词、原始异常或凭据。日志失败不得影响业务控制流，终态日志只在持久结算成功之后发出。
5. sub-agents:changed 复用单个底层 IPC 监听器并向独立订阅者分发；订阅取消幂等、最后一个取消时解除底层监听、单订阅回调异常不影响其他回调。不提高 EventEmitter 上限，不改变对外 API。
6. 预览快照携带现有 dev-app-update.yml，保留现有真实更新检查政策。配置缺失时给出明确本地诊断，不伪造远端更新成功、不修改更新源。冻结快照不原地修改，修复需新预览进程加载。

## 审查收紧

- 数字 OS 错误码只恢复跨平台明确的 2（文件不存在）；不混用 Windows/Unix 的其他数字码。设备、权限和未知 I/O 继续停止。
- 中止批次时为剩余调用补 TOOL_NOT_EXECUTED 工具结果及 rejected 验收证据，不执行剩余操作，不遗留 pending 卡片或缺失的工具结果配对。
- 将既有结果格式化/等待与错误映射原样提取至 subAgentRunResults.ts，控制主循环文件体积；协议不变。
- 主进程公共 snowLogger 使用 Promise 边界同时隔离 native 同步抛错和异步拒绝，保留 pendingWrites/flushLogs 契约。子代理 scope 拒绝日志不再记录可能包含本地路径的项目 ID，只记录父会话安全标识及归属匹配布尔值；这收紧 ADR11 旧诊断字段，不改变权限判定。

- 致命错误和恢复预算耗尽后，首次进入及每轮强行发送循环均检查当前运行错误/取消状态；不清除旧错误或消费后续暂存输入来重开同一 run。

## 验收

不创建测试文件、不操作 Git、不读取或改写真实会话数据库、不调用真实收费模型或更新下载。主代理统一执行相关源文件 LSP 诊断、现有文档/格式守卫及完整构建，使用内存隔离探针验证恢复分类、订阅清理和预览复制。真实子代理 IPC、临时文件生产者和应用 UI 的复验必须区分为另行运行验收，不能用编译成功替代。
