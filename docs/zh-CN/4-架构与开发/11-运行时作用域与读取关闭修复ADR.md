# ADR：运行时作用域、只读快照与 LSP 关闭边界

- 日期：2026-10-23
- 状态：源码修复、完整构建、文档/格式守卫、真实读取探针及限定源码复核已完成；重启后的子代理与 LSP 场景验收尚未执行。Rust LSP 的补充 rustc 推送诊断超时，已由完整 Rust 构建补充验证。
- 范围：日志中的子代理作用域拒绝、只读缓存旁路读取错误和 LSP 回收关闭。

## 已核实事实

1. Electron 与 Rust 分别校验父会话是否存在及其项目归属。保留这两层隔离；不能用全局活动项目替代父会话的持久项目绑定。
2. 内置 filesystem-read 已展开主目录且支持目录。前端 ReadonlyCallGuard 却把 `~/...` 拼到工作区下，再用仅接受文件的 readFileContent 读取目录。旁路快照的错误不等于主工具失败。
3. LSP shutdown 发送 exit 后立即 abort 负责管道收发的 mainloop；exit 通知入队不等于已写入服务器 stdin。

## 决策

- 不修改数据库结构、工具权限、父子会话隔离、MCP 握手策略或业务存储时间契约；不新增依赖。
- 修正子代理调用方持久身份与生命周期，不在权限门禁中容忍错误 scope。只在新运行成功受理后按 runId 登记；终态提交仅退役该 run，父会话确实缺失时退役该父作用域并关闭本地唤醒。组件失效后不再派发后续查询；合并重叠取消观察并保留期间的新变更，旧查询不得取消已退役 run。拒绝日志记录操作与实际/请求项目身份，不包含任务正文。
- 只读快照保留 `~` 的主目录语义，经既有路径解析接口解析准确条目，再分别读取文件或目录。不用异常试读识别目录，不用项目内后缀搜索替代快照目标。无法取得快照时不复用旧结果。
- 主目录展开复用 Rust 公共 expand_home_dir；不在 renderer 硬编码用户名、磁盘或 Shell HOME。
- LSP 关闭遵循 shutdown 请求、exit 通知、保持通信并有界等待子进程退出、必要时强制终止、最后回收通信任务。记录真实关闭失败，不吞掉问题或屏蔽 rust-analyzer 错误。
- 缺少具体路径的 rust-analyzer 监听警告不做猜测性配置修改；正常 legacy handshake 提示不当成故障修复。

## 验证

主代理统一执行支持源文件的 LSP 诊断、TypeScript/Rust 编译、文档守卫与完整本地构建。可复现探针仅使用项目源码和明确的非敏感文档，不创建测试文件、不操作真实会话数据、不执行 Git。编译通过不代表运行中宿主已加载新代码，真实应用复验需新进程加载。
